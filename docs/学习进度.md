# 第一次作业学习进度汇报

## 一、学习情况
学了C++基础（数据类型、流程结构、数组、函数、指针）、Ubuntu基本命令（cd/ls/clang++编译）、CMake基础用法，以及Git基本操作。完成了基础题

## 二、作业完成情况
1. 数组反转：使用双指针交换实现原地反转，处理了n=0的情况。
2. 爬楼梯：实现了迭代和记忆化递归两种方法，n=40时结果一致，处理了n=0/1的边界。
3. 二叉树遍历：使用数组存树，按2i+1和2i+2递归实现前序、中序、后序遍历。
4. 成绩统计与安全查询系统：完成了初始化、录入、平均分、安全查询、统计分数段、找最高最低分、打印结果7个函数，并针对n=0和下标越界做了安全处理。

3. 接口名改错，重新对照题目文档修正了函数名。
